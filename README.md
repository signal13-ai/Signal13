# SIGNAL13 — сайт-визитка

Простой портфолио-сайт. Чистый HTML, CSS, JS — без фреймворков.

---

## Структура файлов

```
signal13/
├── index.html     ← главный файл, вся структура сайта
├── style.css      ← все стили и цвета
├── script.js      ← переключатель языков и анимации
├── assets/        ← папка для картинок и файлов
└── README.md      ← эта инструкция
```

## Как открыть сайт локально (на своём компьютере)

1. Скачай все файлы в одну папку
2. Открой файл **index.html** двойным кликом
3. Сайт откроется в браузере

> Видео с YouTube будут работать только при подключении к интернету.

## Как что-то поменять

### Текст
Открой `index.html` в любом текстовом редакторе.
Ищи комментарии вида `<!-- НАЗВАНИЕ — меняй здесь -->` — они показывают где что менять.

### Цвета
Открой `style.css`, найди блок `:root { }` в самом начале.
Меняй значения переменных:
```css
--bg:    #272727;   /* фон страницы */
--text:  #c8c6bc;   /* основной текст */
--muted: #585858;   /* приглушённый текст */
--fest:  #4a7a4a;   /* цвет фестивальных меток */
```

### Добавить видео
В `index.html` найди блок с комментарием `ДОБАВИТЬ НОВОЕ ВИДЕО`.
Скопируй блок `<div class="video-card">...</div>` и вставь туда.
Замени YouTube-ссылку на свою.

### Email
В `index.html` найди `elizavetashefova@gmail.com` — замени в двух местах (href и текст).

## Как загрузить на GitHub

### Первый раз — создать репозиторий

1. Зайди на [github.com](https://github.com) и зарегистрируйся (если нет аккаунта)
2. Нажми кнопку **"New repository"** (зелёная, правый верхний угол)
3. Название: `signal13` (или любое другое)
4. Оставь **Public** (публичный)
5. Нажми **"Create repository"**

### Загрузить файлы

6. На странице репозитория нажми **"uploading an existing file"**
7. Перетащи все файлы (`index.html`, `style.css`, `script.js`, папку `assets`)
8. Внизу нажми **"Commit changes"**

---

## Как опубликовать через GitHub Pages (бесплатно!)

После загрузки файлов:

1. Зайди в **Settings** репозитория (вкладка сверху)
2. В левом меню выбери **Pages**
3. В разделе **"Branch"** выбери `main` и нажми **Save**
4. Подожди 1-2 минуты
5. Страница обновится и покажет адрес вида:
   ```
   https://ИМЯ_АККАУНТА.github.io/signal13
   ```
6. Это и есть твой сайт в интернете — делись ссылкой!

### Как обновлять сайт

Просто загружай новые версии файлов на GitHub (как в шаге 6-8 выше).
Сайт обновится автоматически через пару минут.

## Как добавить свой домен (опционально)

Если купишь домен (например `signal13.de`):

1. В настройках GitHub Pages найди поле **"Custom domain"**
2. Введи свой домен
3. У регистратора домена добавь DNS-запись:
   - Тип: `CNAME`
   - Имя: `www`
   - Значение: `ИМЯ_АККАУНТА.github.io`
4. Подожди до 24 часов — домен подключится
